# 합성 설비 요구 사양 역산 연습표

합성 입력에서 개별 조건의 생산성 민감도를 계산한 연습이다. 모든 시간과 확률은 가상이고, 실제 설비 사양이나 공급사 값이 아니다.

각 경계는 다른 조건을 기준값에 둔 개별 민감도이고 동시 허용 사양이 아니다.

검사 시간을 늘려도 검출 성능은 그대로라고 가정한다. 시간과 검사 성능의 관계는 모의하지 않았다.

홀드아웃은 9단계 결과가 공개된 시드의 재사용 확인이고 새 독립 검증이 아니다.

선택 조합 2-1-1, 목표 양품 UPH 181.3953, 기준선 개발 182.8008, 홀드아웃 185.6781.

## 동시 적용

모든 경계를 함께 넣으면 개발 179.6563, 홀드아웃 182.7618, 결과는 **동시 미충족**.

## 측정기 허용 오불합격

허용 오불합격은 최종 양품의 추가 손실을 가정한 최악 산술값이다. 12단계 false_reject는 false_rejects / true_good인 별도 모의의 측정 관측 비율이고, 분모와 적용 대상이 다르다.

| 게이지 | 가드 배수 | 12단계 오불합격 | 12단계 오합격 | 라인 허용값 | 비교 |
| --- | ---: | ---: | ---: | ---: | --- |
| good | 0 | 0.0002 | 0.0124 | 0.0077 | 가정상 산술 비교 이내 |
| marginal | 0 | 0.0006 | 0.0426 | 0.0077 | 가정상 산술 비교 이내 |
| poor | 0.5 | 0.0026 | 0.0480 | 0.0077 | 가정상 산술 비교 이내 |

비교는 측정기 적합 판정이 아니다. 유출 기준은 12단계가 따로 판단한다.

## 실제 적용 전 필요한 확인

| 가정 | 계산한 경계 | 필요한 확인 |
| --- | --- | --- |
| 사이클은 고정 시간이다 | test 경계 | 실측 사이클과 시간 구성 |
| test를 늘려도 검출 성능은 같다 | test 경계 | 검사 성능과 시간의 관계 |
| 정지는 외생이고 수리는 고정 시간이다 | 수리 경계 | 정지·복구 기록 |
| 조건을 하나씩만 바꾼다 | 개별 경계 전부 | 동시 조건 검증 |
