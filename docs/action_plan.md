# 실행 계획: 2026-09-30~10-18

상태: **작업 전 계획**. 기준은 [v6](../../outputs/제조기술개발_프로젝트_주제와핵심기능_v6.md)와 [요구사항](requirements.md)이다. 사용자의 기본 작업 가능 시간은 하루 **4시간**이다. 8시간 확보는 확정된 조건이 아니므로 필수 작업량에 넣지 않는다. 실제 시작 시간이 늦어지면 날짜보다 아래 **검토 관문**의 순서를 우선한다.

## 운영 원칙

- 사용자는 요구사항·예상 결과·범위·채택 여부를 결정하고, AI가 코드를 작성한다.
- 하루 기본 시간의 예: 지시·범위 확인 30분, AI 작업과 실행 확인 2시간, 사용자 결과 검토·코드 이해 1시간, 결정·근거 기록 30분. 실제 소요에 맞춰 조정한다.
- 구현 담당은 요구사항 ID가 붙은 **한 작업 묶음**만 다룬다. 실행 방법·결과·실패까지 보고한다.
- 상위 모델의 별도 검토는 G0(명세), G2(보류·재검사 통합), G3(최종 시연)에서 우선한다. 작은 수정마다 전체를 재검토하지 않는다.
- 10/15 이후 기능을 동결하고 자기소개서·지원 자료에 집중한다. 가능하면 10/17 제출하고 10/18은 마감 대응 여유로 둔다.

## 지연 시 축소 순서

1. 별도 화면 앱, 차트, 외관·광도 검사, 제품 내 GPT 기능을 시작하지 않는다.
2. 10/5에 정상 흐름이 실행되지 않으면 터미널+고정 입력부터 완성한다.
3. 10/10에 재검사 흐름이 통합되지 않으면 표시 꾸미기를 멈추고 FAIL→요청→새 결과의 상태·이력에 집중한다.
4. 10/13에도 전체 흐름이 미완성이면 지원서에는 완성한 범위만 적는다.

하루 8시간을 실제 확보한 날의 추가 시간은 **작동 확인, 이해, 오류 수정, 시연 연습**에 먼저 쓴다. 기본 기능 완료 전에는 새 기능을 추가하지 않는다.
