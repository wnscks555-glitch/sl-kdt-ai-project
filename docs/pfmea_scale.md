# PFMEA 연습 점수 기준 (프로젝트 자체 기준)

이 기준은 합성 공정의 연습용이다. AIAG/VDA 평가표나 AP가 아니며, 실무 평가 기준으로 쓰지 않는다. 합성 수치는 참고 관측치이고 점수로 환산하지 않는다.

- **심각도(S)**: 고장이 일어났을 때 가정한 영향의 크기를 본다.
- **발생도(O)**: 원인이 일어날 가능성과 예방 관리의 수준을 본다. 고장을 처음부터 넣은 실행의 정지율은 O가 아니다.
- **검출도(D)**: 검출 대상, 검출 시점, 관리의 유효성을 본다. 최초 FAIL률의 여집합은 곧바로 D가 아니다.

| 점수 | S | O | D |
| --- | --- | --- | --- |
| 1–2 | 제품 기능에 영향이 없다고 가정 | 원인이 일어나기 어렵게 예방 관리가 있음 | 고장 직후 공정 안에서 자동으로 거의 항상 검출 |
| 3–4 | 다음 공정에서 쉽게 복구 | 드물게 일어나며 예방 관리가 있음 | 공정 안에서 자동 검출되나 놓칠 수 있음 |
| 5–6 | 재작업이 필요 | 가끔 일어나고 예방 관리가 부분적임 | 뒤 공정이나 사후 보고서로 검출 |
| 7–8 | 주요 기능을 잃는다고 가정 | 자주 일어나고 예방 관리가 약함 | 사람의 판단이나 표본 확인에 의존 |
| 9–10 | 안전이나 법규 요구에 닿는다고 가정 | 일어나는 것을 막을 관리가 없음 | 검출 수단이 없거나 검출을 기대할 수 없음 |

- `rpn`은 S × O × D의 표시값이다. 합격 판정에 쓰지 않는다.
- `priority=우선`은 S가 9 이상인 행이다. 빈칸은 저위험이 아니라 표시 대상이 아니라는 뜻이다.
- `rpn_change`는 숫자 차이다. 그만큼 위험이 줄었다는 뜻이 아니다. 조치 전후 관리 상태를 함께 읽는다.
